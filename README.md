# Propuestas web para hoteles

Repositorio público para organizar propuestas de páginas web, imágenes ilustrativas e información comercial pública de hoteles. Los materiales se preparan para que Muse pueda revisarlos y enviar los que correspondan.

## Estructura por hotel

Cada hotel tendrá una carpeta en `hoteles/<nombre-del-hotel>/` con:

- `ficha.md`: nombre comercial, ubicación pública, sitio oficial, contacto comercial publicado y fuentes consultadas con fecha.
- `propuesta.md`: alcance de la propuesta y enlaces a los diseños.
- `imagenes/`: vistas ilustrativas de la página propuesta. Cada imagen debe identificarse como propuesta, no como sitio publicado ni fotografía real del hotel.

La carpeta `plantillas/` contiene formatos vacíos. No representa hoteles reales.

## Antes de enviar

**Criterio de selección: únicamente hoteles sin página web propia.** Los hoteles con sitio propio no son elegibles y sus propuestas no deben enviarse.

Muse debe comprobar el historial de contacto y los envíos anteriores para evitar duplicados, confirmar el destinatario y revisar que los materiales correspondan al hotel. Si el historial no está disponible, debe quedar pendiente de revisión. El historial de comunicaciones y cualquier información privada se conservan fuera de este repositorio público.

La presencia de un archivo no demuestra que haya sido enviado. Este repositorio no configura envíos automáticos ni conexiones con Muse.

## Contenido público

Publicar únicamente información comercial que ya sea pública y propuestas autorizadas para compartir. No incluir contraseñas, claves de acceso, datos privados, conversaciones, documentos internos ni información de huéspedes. Registrar las fuentes y usar únicamente imágenes propias o con permiso para publicarlas. No inventar datos, contactos, testimonios, tarifas ni características de los hoteles.
